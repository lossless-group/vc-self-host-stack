## Why Care?

[[2026-11-01_01]] made this repo's `context-v/` folders Open Knowledge Format
bundles. This pass brings the same docs up to the Context Vigilance Kit's
frontmatter template, so a workflow dashboard can tell which rules are in
force, which handoff is the live pickup point, which issues are still open,
and which specs actually shipped.

## What's New?

- **The four reminders are `Active`.** They were `Draft`, but each is a rule
  already in force.
- **Handoffs say whether they're spent.** The 2026-08-08 handoff is
  `Superseded`, pointing at the 2026-08-15 one, whose own body says it
  replaces it. The 2026-08-15 handoff is `Archived`. The Cal.diy pickup stays
  the live one, `Active`, since nothing since shows Google approving the app.
  The July pickup plan, also consumed, is `Archived`.
- **Shipped specs say so, with dates from commits.** The Papermark spec is
  `Shipped`: the data room it describes went live on 2026-08-03. The
  Twenty-First deployment spec is `Partially-Shipped`: phases 0–3 and 5
  landed on 2026-07-25, while phase 4's stakeholder run and the phase 6
  spike haven't happened.
- **The Edviro plan is `Implementing`**: its HubSpot wrapper is deployed in
  `hubs/hubspot-mcp`, and the hand-over phase is still ahead.
- **Decisions say `Decided`.** Both decision records, including event-hog's.
- **Path normalization is an `Open` issue**, not `Partially-Shipped`: the
  readable addresses shipped, but the MCP connector path still needs a proxy.
- **The path-model decision** gained `date_modified` and `authors` from its
  git history.
- **Tags:** `lossless.at` and `didi.sh` became `Lossless-At` and `Didi-Sh`,
  the spelling the rest of the tree already uses. The repo's own name,
  `Self-Host-Stack`, came out of the tags on eight docs whose bodies already
  name the repo; the four that don't keep it.

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan,
