## Why Care?

The per-client hub exists so a stakeholder needs exactly one bookmark, no
matter how many tools their stack grows. Today it grew: Outline went from
"deployed last night" to "working in production" — workspace live,
collections populated, API key minted, first documents written by an agent
through the REST API — so the hub now surfaces it.

## What's New?

- **"Your Knowledge Base" card** on the client hub, linking to the client's
  Outline instance. Config-driven: an optional `wiki_url` per client in
  `hub/src/config/clients.ts`, rendered only for clients that have one —
  palmer-ai gets the card, reach-edu's page is unchanged until its own
  Outline exists.
- **README** now marks Outline as working in production (deployed
  2026-07-27, verified end-to-end the same day), alongside yesterday's
  our-pick callout and the Docmost API-license post-mortem.
