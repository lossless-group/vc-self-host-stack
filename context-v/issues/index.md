# Issues

* [Normalize Paths Everywhere — one URL shape for every client + service](Normalize-Paths-Everywhere.md) - Today every tool lives at a raw Railway hostname; the goal is one owned, legible shape — lossless.at/<client>/<service>/… — for humans and agents alike.
* [Postiz is the heaviest thing we run](Postiz-Is-The-Heaviest-Thing-We-Run.md) - Postiz and its dependencies account for more than half the memory in the client projects that have it — and memory is 93% of the Railway bill. Nobody is visibly getting value back.
* [Which domain hosts what — lossless.at vs didi.sh](Which-Domain-Hosts-What-lossless-at-vs-didi-sh.md) - Client-facing apps have landed on both domains by accident of chronology, not decision. Nothing is broken; the next deploy will guess, and guess differently than the last one.
